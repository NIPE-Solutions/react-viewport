# Code of Conduct

## Our standard

We want a respectful, constructive environment for everyone participating in
this project. Be considerate, communicate in good faith, welcome differing
perspectives, and focus criticism on ideas and work rather than people.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, unwanted sexual
attention, deliberate intimidation, publishing private information, and other
conduct that makes participation unsafe or hostile are not acceptable.

## Enforcement

Project maintainers may remove or edit contributions, warn participants, limit
participation, or take other proportionate action to protect the community.
For sensitive concerns, do not open a public issue; use a private channel you
already have with a project maintainer. This alpha repository does not publish a
separate conduct-reporting address.

This Code of Conduct applies to project spaces and to public interactions when a
person is representing the project.
